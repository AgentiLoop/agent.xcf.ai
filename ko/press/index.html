제품 개요
AgentiLoop Agent!는 데스크탑에서 AI가 직접 일하게 하는 Mac 앱입니다. 원하는 작업을 입력하고 21개 AI 제공자 중 하나를 선택하면, 에이전트가 작업이 끝날 때까지 읽고, 쓰고, 빌드하고, 클릭하고, 스크립트를 실행합니다. MIT 라이선스 기반 오픈 소스입니다.

제품 설명

AgentiLoop Agent! 소개

AgentiLoop Agent!는 코드 편집기만이 아니라 컴퓨터 전체를 AI에게 맡기는 Mac 앱입니다. Xcode 프로젝트를 빌드하고, 다른 앱을 조작하고, 스크립트를 실행하며, 일반 영어로 된 요청만으로 작업을 완수합니다.

대부분의 AI 코딩 도구는 터미널, 편집기 또는 Electron 창 안에서 동작하며, 그 영향력은 파일 시스템에서 끝납니다. Mac의 나머지 부분, 즉 앱, 창, 메뉴, 스크립트, 빌드 도구는 손이 닿지 않는 영역으로 남습니다.

AgentiLoop Agent!는 순수 Swift 6.2와 SwiftUI로 만들어졌습니다. Electron도, Node도, 텔레메트리도 없습니다. 계획하고, 도구를 호출하고, 실제 결과를 관찰하고, 방향을 수정하고, 반복하는 자율 루프를 실행하며, 목표 기준이 근거와 함께 완료로 표시되기 전에는 어떤 작업도 스스로 완료를 선언할 수 없습니다. 선택적으로 크리틱 단계가 먼저 diff를 검토합니다.

Mac의 모든 계층에 접근합니다. Accessibility API, AppleScript, JavaScript for Automation 및 51개의 ScriptingBridge 앱 브리지를 통한 모든 앱 제어, 클릭 가능한 오류가 표시되는 네이티브 Xcode 빌드, 사용자 권한 또는 한 번만 승인하면 되는 데몬을 통한 루트 권한의 셸 명령 실행. Model Context Protocol 서버, 런타임에 컴파일되는 Swift 스크립트, 병렬 서브 에이전트로 확장할 수 있습니다. 음성으로 “Agent!”라고 부르거나 iPhone에서 iMessage를 보내면 응답합니다.

어떤 모델로도 구동할 수 있습니다. Claude, OpenAI, Gemini, DeepSeek, Qwen, OpenRouter, Requesty, A2Agent, OrcaRouter, 로컬 Ollama, vLLM, LM Studio 등 21개 제공자와 더불어, 온디바이스 Apple Intelligence가 토큰 비용 없이 분류, 요약, 컨텍스트 압축을 처리합니다. 자신의 API 키를 사용하세요. 프롬프트로 선택한 제공자에게 전송되는 내용 외에는 아무것도 Mac 밖으로 나가지 않으며, 모든 동작이 기록됩니다.

주요 기능

AgentiLoop Agent!가 하는 일

앱 전체를 관통하는 하나의 아이디어: AI는 사람이 Mac에서 할 수 있는 모든 일을 할 수 있어야 하며, 그 과정을 보여 주어야 합니다.

  • 자체 검증 작업 루프. 에이전트는 추론하고, 도구를 실행하고, 실제 출력을 관찰하고, 스스로 수정합니다. 목표 기준이 근거와 함께 검증되기 전에는 작업을 완료로 표시할 수 없으며, 선택적으로 크리틱이 완료 전에 diff를 검토합니다.
  • 네이티브 Xcode 통합을 갖춘 에이전틱 코딩. 코드베이스를 읽고, 문자열 치환 diff로 편집하고, 클릭 가능한 오류와 함께 Xcode 프로젝트를 빌드·실행하고, git을 관리하고, 버전을 올리고, 저장소를 이식 가능한 JSONL 저장소 맵으로 색인합니다.
  • Accessibility API를 통한 데스크탑 자동화. 퍼지 자동 재시도 기능으로 모든 Mac 앱을 요소 단위로 클릭, 입력, 스크롤, 읽기, 탐색하며, AppleScript, JavaScript for Automation 및 51개의 ScriptingBridge 앱 브리지를 모두 인프로세스로 지원합니다.
  • AgentScript: 런타임에 컴파일되는 Swift 스크립트. 에이전트가 일반 Swift 파일을 작성하고, Swift Package Manager로 동적 라이브러리로 컴파일한 뒤, 앱 자체의 권한으로 인프로세스에 로드합니다. 약 35개의 예제가 앱과 함께 제공되며, 삭제된 스크립트는 복원 가능한 휴지통으로 이동합니다.
  • 모든 편집을 되돌릴 수 있습니다. 각 파일 편집은 실행 전에 스냅샷으로 저장되어 일주일간 보관되며, UI에서 원클릭 롤백, 실행 취소 동작 또는 작업 전체 되감기가 가능합니다.
  • 21개 LLM 제공자와 폴백 체인. Claude, Codex, OpenAI, Google Gemini, Grok, Mistral, Mistral Vibe, DeepSeek, Hugging Face, Z.ai, BigModel, Qwen, MiniMax, OpenRouter, Requesty, A2Agent, OrcaRouter, Ollama, 로컬 Ollama, vLLM, LM Studio와 더불어 온디바이스 Apple Intelligence를 지원합니다. 제공자가 실패하거나 속도 제한에 걸리면 에이전트가 다음으로 구성된 제공자로 전환합니다.
  • 온디바이스 에이전트로서의 Apple Intelligence. Apple의 Foundation Models가 간단한 요청을 로컬에서 분류하고, 완료된 작업을 요약하고, 도구 오류를 쉬운 말로 풀어 설명하고, 다음 단계를 제안하고, 긴 대화를 압축합니다. 이 모든 과정이 Mac을 벗어나거나 API 토큰을 소비하지 않고 이루어집니다.
  • 사용자가 한 번만 승인하는 권한 실행. 셸 명령은 Launch Agent를 통해 사용자 권한으로, 또는 Launch Daemon을 통해 루트 권한으로 실행되며, SMAppService로 등록되고 XPC로 연결됩니다. Launch Daemon은 선택 사항입니다.
  • 심층 방어. 셸 안전 서비스가 클라이언트와 데몬 양쪽에서 치명적인 명령을 차단하고, 두 XPC 리스너 모두 앱 자체 서명에서 파생된 동일 팀 코드 서명을 요구하며, 모델이 읽지 않았거나 디스크에서 변경된 파일에 대한 편집은 거부되고, 모든 도구 호출과 헬퍼 명령이 감사 로그에 기록됩니다.자세한 내용: docs/SECURITY.md
  • MCP 서버와 서브 에이전트. 어떤 Model Context Protocol 서버든 설정에서 추가할 수 있으며, 해당 도구가 에이전트에 자동으로 표시됩니다. 최대 3개의 동시 서브 에이전트 또는 6개의 읽기 전용 서브 에이전트가 에이전트별 모델 재정의와 메일박스 메시징을 갖추고 격리된 환경에서 작업합니다.
  • 음성 및 iMessage 원격 제어. “Agent!”에 이어 작업을 말하면 온디바이스 음성 인식을 사용하여 잠시 침묵 후 실행됩니다. 승인된 발신자는 iPhone에서 문자로 작업을 보내고 iMessage로 결과를 받을 수 있습니다.
  • 탭, 메모리, 계획, 스킬. 각 탭은 고유한 프로젝트 폴더와 활동 로그를 가지며, 영구 메모리가 작업 간에 이어지고, 다단계 계획 체크리스트가 모든 프롬프트에 표시되며, 긴 작업은 각 모델의 실제 컨텍스트 창에 맞게 압축됩니다.
