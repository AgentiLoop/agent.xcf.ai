AgentiLoop Agent!

Mac 데스크톱을 위한 에이전틱 AI

하나의 앱. 어떤 AI든. 당신을 위해 일하는 Mac. AgentiLoop Agent!는 이메일에 답장하고, Safari를 자동화하고, 앱을 만들고, 코드를 작성하고, 파일을 정리하고, 즐겨 쓰는 Mac 앱을 조작합니다 — 필요한 것을 말하기만 하세요. 일상 작업을 자연어만으로 손이 필요 없는 워크플로로 바꾸세요. 100% 네이티브 Swift. macOS 26 및 27에서 실행됩니다.

약속이 아닌 증거

실제 세션, 실제 결과 — 작업 중인 Agent!에서 그대로 캡처했습니다.

명령 한 번으로 Xcode 버전 올리기

"버전 올려줘"라고 말하면 Agent!가 현재 버전을 읽고, 프로젝트 설정을 업데이트하고, 빌드로 검증한 뒤 변경 사항을 커밋합니다. plist를 직접 편집할 필요도, 빌드 번호를 놓칠 일도 없습니다.

추측하기 전에 묻습니다

요청이 모호하면 Agent!는 멈추고 질문합니다. 몰래 잘못된 길을 택하지 않습니다 — 간단한 프롬프트와 보내기 또는 건너뛰기로 언제나 주도권은 당신에게 있습니다.

Claude Code가 검토하고 승인

Agent!는 Claude Code가 여러 차례 검토에서 놓친 자체 손쉬운 사용 코드의 라우팅 버그를 스스로 찾아 수정했습니다. Claude Code가 수정 사항을 검토했을 때, 패치가 올바르다고 확인했습니다.

한 세션 만에 플레이 가능한 게임 완성

Ticky Tacky는 봇 대전 및 2인 모드, 세 가지 난이도, 저장되는 점수를 갖춘 네온 틱택토로, 의존성이 전혀 없는 순수 HTML, CSS, JavaScript 게임입니다. Agent!가 단 한 세션 만에 만들었습니다.

Apple Intelligence — 진짜 에이전트로

Agent!는 온디바이스 Apple Intelligence를 단순한 텍스트 생성기가 아닌 도구 호출 에이전트로 사용하는 유일한 Mac AI 에이전트입니다. 아래의 모든 기능은 Mac에서 실행되며, 기기 밖으로 나가지 않고, API 토큰을 전혀 소비하지 않습니다.

1다음 단계 제안

작업이 끝나면 Apple Intelligence가 온디바이스에서 결과를 읽고 논리적인 다음 행동을 한 문장으로 제안합니다 — "커밋하고 푸시하기", "테스트 실행하기", 또는 뚜렷한 후속 작업이 없다면 아무것도 제안하지 않습니다. 클라우드 왕복도, 토큰 소비도 없습니다.

2토큰 압축

약 30,000 토큰을 넘는 긴 작업은 이전 턴을 온디바이스에서 요약합니다 — 파일 경로, 함수 이름, 오류, 핵심 결과는 유지하면서 — 남은 작업의 입력 토큰과 비용을 크게 줄입니다.

3로컬 분류

잡담이나 "list agents", "run agent FooBar" 같은 직접 명령은 클라우드 LLM 왕복 없이 로컬에서 처리됩니다 — 결과는 1초 안에 활동 로그에 🍎 표시와 함께 나타납니다.

4요약 & 알기 쉬운 오류

작업이 완료될 때마다 Apple Intelligence가 한 문장 요약을 작성합니다. 도구가 실패하면 오류를 알기 쉬운 말로 풀어 주어, 날것의 스택 트레이스를 읽을 일이 없습니다.

Brew로 설치하거나 다운로드하고, AI를 고르세요. 나머지는 Agent!가 자동으로 설정합니다.

1

사전 요구 사항

  • macOS 26.4 (Tahoe) 이상, Apple Silicon 권장
  • Xcode 명령어 도구: xcode-select --install
  • LLM API 키 — 또는 Ollama, vLLM, LM Studio를 통한 로컬 모델
2

설치 & 실행

  • Homebrew: brew install --cask agentiloop-agent
  • 또는 DMG를 다운로드하여 Agent!를 /Applications로 드래그
  • Agent!를 열고 Register를 클릭해 백그라운드 서비스를 설치
3

승인 & 설정

  • 시스템 설정 → 로그인 항목에서 Agent와 AgentHelper를 허용
  • 설정(⚙️)을 열고, 제공자를 고른 뒤, API 키를 입력
  • Connect를 클릭해 XPC 서비스를 테스트
4

시작

  • 자연어로 작업을 입력
  • Run을 누르기 (또는 ⌘Enter)
  • 이제 Agent!가 알아서 합니다 — 음성, iMessage, 핸즈프리 제어까지
