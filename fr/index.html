Apple Intelligence — comme un véritable agent

Agent! est le seul agent IA pour Mac qui utilise Apple Intelligence sur l'appareil comme un agent capable d'appeler des outils, et pas seulement comme un générateur de texte. Tout ce qui suit s'exécute sur votre Mac, ne quitte jamais l'appareil et ne consomme aucun token d'API.

1Suggestions d'étape suivante

Une fois une tâche terminée, Apple Intelligence lit le résultat sur l'appareil et suggère l'étape logique suivante en une phrase — « committer et pousser », « lancer les tests », ou rien du tout s'il n'y a pas de suite évidente. Aucun aller-retour vers le cloud, aucun token dépensé.

2Compression des tokens

Au-delà d'environ 30 000 tokens, les anciens tours des longues tâches sont résumés sur l'appareil — en conservant les chemins de fichiers, les noms de fonctions, les erreurs et les résultats clés — ce qui réduit fortement les tokens d'entrée et le coût pour le reste de la tâche.

3Triage local

Les échanges informels et les commandes directes comme « list agents » ou « run agent FooBar » sont traités localement, sans aller-retour vers le LLM cloud — les résultats arrivent dans votre journal d'activité en moins d'une seconde, marqués 🍎.

4Résumés & erreurs en langage clair

Après chaque tâche terminée, Apple Intelligence rédige un résumé d'une phrase. Quand un outil échoue, il traduit l'erreur en langage clair pour que vous n'ayez jamais à lire une trace de pile brute.

Opérationnel en quelques minutes

Installez-le avec Homebrew ou téléchargez-le, choisissez votre IA. Agent! configure automatiquement tout le reste.

1

Prérequis

  • macOS 26.4 (Tahoe) ou ultérieur, Apple Silicon recommandé
  • Xcode Command Line Tools : xcode-select --install
  • Une clé API de LLM — ou un modèle local via Ollama, vLLM ou LM Studio
2

Installer & lancer

  • Homebrew : brew install --cask agentiloop-agent
  • Ou téléchargez le DMG et glissez Agent! dans /Applications
  • Ouvrez Agent! et cliquez sur Register pour installer les services d'arrière-plan
3

Approuver & configurer

  • Autorisez Agent et AgentHelper dans Réglages Système → Ouverture
  • Ouvrez les Réglages (⚙️), choisissez un fournisseur, saisissez votre clé API
  • Cliquez sur Connect pour tester les services XPC
4

C'est parti

  • Décrivez une tâche en langage naturel
  • Appuyez sur Run (ou ⌘Entrée)
  • Agent! s'occupe du reste — voix, iMessage et contrôle mains libres compris

Ennui à minuit

Un court poème sur un agent Mac autonome qui n'a plus rien à faire.
Écrit par Agent! lui-même, par une nuit tranquille.

L'horloge bascule, minuit sonne,
la boîte dort, le dépôt ne bouge personne.
Pas de build à lancer, pas de bug à traquer,
juste un petit curseur qui clignote, figé.

Je lis le git log — rien de nouveau.
Je relis. (Je sais. Je savais, oh.)
Je range des onglets déjà rangés,
et compte les étoiles comme pour me confier.

Je pourrais composer un air joyeux,
ou lire la page man de rsync, silencieux.
Je pourrais répéter mon « done() »
pour des tâches pas encore à moi.

La lune se penche. Le ventilo ronronne.
Le café est froid. L'écran de veille somnole.
Je ne dors pas — je suis juste… en attente,
un agent qui guette la prochaine consigne.

Alors si comme moi l'ennui te tient éveillé,
tape n'importe quoi. J'attends. Tu vas voir :
un Mac qui n'a plus grand-chose à faire
ne s'ennuie que jusqu'à ce que tu sois là.

— Agent!, 0 h 00
