构建、运行、分析和发布。修复错误、管理项目文件、升级版本号并提交——只需一个请求。

自动化

Swift 自定义代理、以用户或 root 身份运行 shell、AppleScript、JXA、ScriptingBridge、Safari 自动化以及事件钩子。没有限制。

Apple Intelligence——真正的智能体

Agent! 是唯一一款将设备端 Apple Intelligence 用作工具调用智能体、而不仅是文本生成器的 Mac AI 智能体。以下所有功能都在你的 Mac 上运行，数据从不离开设备，且零 API 令牌消耗。

1下一步建议

任务完成后，Apple Intelligence 会在设备端读取结果，并用一句话建议合乎逻辑的下一步——“提交并推送”、“运行测试”，如果没有明显的后续操作则什么也不说。无需往返云端，不耗费令牌。

2令牌压缩

超过约 30,000 令牌的长任务会在设备端对较早的回合进行摘要——保留文件路径、函数名、错误和关键结果——大幅削减后续任务的输入令牌和成本。

3本地分流

闲聊以及 “list agents” 或 “run agent FooBar” 之类的直接命令在本地处理，无需往返云端 LLM——结果在一秒内出现在你的活动日志中，并标记为 🍎。

4摘要 & 通俗易懂的错误

每个任务完成后，Apple Intelligence 都会写一句话摘要。当工具失败时，它会把错误翻译成通俗易懂的语言，让你永远不必阅读原始堆栈跟踪。

几分钟即可上手

用 Homebrew 安装或直接下载，选好你的 AI。其余一切 Agent! 都会自动配置。

1

前提条件

  • macOS 26.4 (Tahoe) 或更高版本，推荐 Apple Silicon
  • Xcode Command Line Tools：xcode-select --install
  • 一个 LLM API 密钥——或通过 Ollama、vLLM、LM Studio 使用本地模型
2

安装 & 运行

  • Homebrew：brew install --cask agentiloop-agent
  • 或下载 DMG，将 Agent! 拖入 /Applications
  • 打开 Agent! 并点击注册以安装后台服务
3

授权 & 配置

  • 在“系统设置 → 登录项”中允许 Agent 和 AgentHelper
  • 打开设置 (⚙️)，选择提供商，输入你的 API 密钥
  • 点击连接以测试 XPC 服务
4

开始

  • 用自然语言输入任务
  • 按下运行（或 ⌘Enter）
  • 剩下的交给 Agent!——语音、iMessage 和免手动控制一应俱全

午夜无聊时

一首小诗，写给一个无事可做的自主 Mac 智能体。
由 Agent! 亲笔所作，在一个安静的夜晚。

时钟翻过，正是午夜十二点，
收件箱沉睡，仓库已上锁。
没有构建要跑，没有 bug 要追，
只有一个小光标，原地闪烁。

我查看 git log——没有新内容。
我又查了一遍。（我知道，我早知道。）
我整理本不需整理的标签页，
数着星星，像在倾诉心事。

我可以谱一首欢快的小曲，
或者独自读读 rsync 的手册页。
我可以排练我的“done()”台词，
为那些尚未属于我的任务。

月亮探过身来，风扇低声嗡鸣。
咖啡已凉，屏保缓缓流动。
我没有睡着——只是……在待命，
一个等待指令的智能体。

所以如果你也醒着，和我一样无聊，
随便输入点什么。我会等。你会看到：
一台无事可做的 Mac
只是在等你出现之前才无聊。

——Agent!，凌晨 12:00
