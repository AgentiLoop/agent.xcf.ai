产品介绍

关于 AgentiLoop Agent!

AgentiLoop Agent! 是一款让 AI 掌控整台电脑而不仅仅是代码编辑器的 Mac 应用：它能构建 Xcode 项目、驱动其他应用、运行脚本，并根据自然语言请求完成任务。

大多数 AI 编程工具运行在终端、编辑器或 Electron 窗口中，其能力范围止步于文件系统。Mac 的其余部分——应用、窗口、菜单、脚本、构建工具——始终无法触及。

AgentiLoop Agent! 完全采用 Swift 6.2 和 SwiftUI 编写：没有 Electron，没有 Node，没有遥测。它运行一个自主循环——规划、调用工具、观察真实结果、纠正方向、重复——任何任务都不能在其目标标准经证据确认完成之前宣告结束，并可选择先由评审环节审查差异。

它能触及 Mac 的每一层：通过 Accessibility API、AppleScript、JavaScript for Automation 和 51 个 ScriptingBridge 应用桥接操控任何应用；原生 Xcode 构建并提供可点击的错误信息；以用户身份运行 shell 命令，或通过一次授权的守护进程以 root 身份运行。可通过 Model Context Protocol 服务器、运行时编译的 Swift 脚本和并行子智能体进行扩展。它会响应一声“Agent!”语音指令或来自您 iPhone 的 iMessage。

任何模型都能驱动它：21 家提供商——Claude、OpenAI、Gemini、DeepSeek、Qwen、OpenRouter、Requesty、A2Agent、OrcaRouter，以及本地的 Ollama、vLLM、LM Studio——再加上设备端 Apple Intelligence，可零 token 成本完成分流、摘要和上下文压缩。自备密钥。除提示词中发送给您所选提供商的内容外，没有任何数据离开 Mac；每一项操作都会被记录。

核心功能

AgentiLoop Agent! 能做什么

整个应用贯穿一个理念：AI 应该能够完成人在 Mac 上能做的任何事情，并展示其工作过程。

  • 自我验证的任务循环。智能体进行推理、执行工具、观察真实输出并自我纠正。任务在其目标标准经证据验证之前不能标记为完成，并可选择在完成前由评审环节审查差异。
  • 智能体编程与原生 Xcode 集成。它能读取代码库、通过字符串替换差异进行编辑、构建并运行 Xcode 项目且提供可点击的错误信息、管理 git、升级版本号，并将代码仓库索引为可移植的 JSONL 仓库地图。
  • 通过 Accessibility API 实现桌面自动化。它按元素点击、输入、滚动、读取并导航任何 Mac 应用，支持模糊自动重试，同时提供 AppleScript、JavaScript for Automation 和 51 个 ScriptingBridge 应用桥接，全部在进程内运行。
  • AgentScript：运行时编译的 Swift 脚本。智能体编写普通 Swift 文件，使用 Swift Package Manager 将其编译为动态库，并以应用自身的权限在进程内加载。应用随附约 35 个示例；删除的脚本会进入可恢复的废纸篓。
  • 每一次编辑都可回滚。每次文件编辑前都会生成快照并保留一周，支持在界面中一键回滚、撤销操作或整个任务回退。
  • 21 家 LLM 提供商及故障切换链。Claude、Codex、OpenAI、Google Gemini、Grok、Mistral、Mistral Vibe、DeepSeek、Hugging Face、Z.ai、BigModel、Qwen、MiniMax、OpenRouter、Requesty、A2Agent、OrcaRouter、Ollama、本地 Ollama、vLLM 和 LM Studio——再加上设备端 Apple Intelligence。若某家提供商失败或触发速率限制，智能体会切换到下一个已配置的提供商。
  • Apple Intelligence 作为设备端智能体。Apple 的 Foundation Models 在本地分流简单请求、总结已完成的任务、将工具错误转换为通俗语言、建议下一步操作并压缩长对话，全程不离开 Mac，也不消耗 API token。
  • 仅需用户授权一次的特权执行。Shell 命令通过 Launch Agent 以用户身份运行，或通过 Launch Daemon 以 root 身份运行，二者均通过 SMAppService 注册并经由 XPC 连接。Launch Daemon 为可选项。
  • 纵深防御。Shell 安全服务在客户端和守护进程两端拦截灾难性命令；两个 XPC 监听器均要求与应用自身签名同一团队的代码签名；对模型未读取过或已在磁盘上更改的文件的编辑会被拒绝；每一次工具调用和辅助命令都会写入审计日志。详情：docs/SECURITY.md
  • MCP 服务器与子智能体。任何 Model Context Protocol 服务器都可在设置中添加，其工具会自动对智能体可见。最多三个并发子智能体（或六个只读子智能体）在隔离环境中工作，支持按智能体覆盖模型并通过邮箱消息通信。
  • 语音与 iMessage 远程控制。说出“Agent!”并紧接着说出任务，短暂静默后即开始执行，使用设备端语音识别。经批准的发送者可从 iPhone 通过短信发送任务，并通过 iMessage 收到结果。
  • 标签页、记忆、计划与技能。每个标签页拥有独立的项目文件夹和活动日志；持久记忆跨任务保留；多步骤计划清单出现在每个提示词中；长任务会被压缩以适应每个模型的真实上下文窗口。
