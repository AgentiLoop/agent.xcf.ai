AgentiLoop Agent!

Mac デスクトップのためのエージェント型 AI

一つのアプリ。どんな AI でも。あなたの Mac が、あなたのために働きます。AgentiLoop Agent! はメールに返信し、Safari を自動操作し、アプリを作り、コードを書き、ファイルを整理し、お気に入りの Mac アプリを操作します — 必要なことを伝えるだけ。日々の作業を、すべて自然言語でハンズフリーのワークフローに。100% ネイティブ Swift。macOS 26 および 27 で動作。

🖥️

デスクトップ操作

自然言語であらゆる Mac アプリを操作。クリック、入力、スクロール、ナビゲーション — アクセシビリティ API で実現。AppleScript は不要です。

✏️

エージェント型コーディング

精密な文字列置換による編集、ワンクリックの Time Machine 風ロールバック、ポータブルな JSONL リポジトリマップ、そして証拠に基づいて完了を確認する自己検証タスク。

🛠️

Xcode 統合

ビルド、実行、解析、そしてリリース。エラー修正、プロジェクトファイル管理、バージョン更新、コミットまで — すべて一つのリクエストで。

🔄

自動化

Swift によるカスタムエージェント、ユーザーまたは root としてのシェル、AppleScript、JXA、ScriptingBridge、Safari 自動化、イベントフック。制限はありません。

🧠

Apple Intelligence

単なるテキスト生成ではなく、オンデバイスのツール呼び出しエージェント。意図の解析、コンテキスト圧縮、トリアージ、タスク要約。プライベート、無料、API トークンはゼロ。

🔌

MCP 対応

Model Context Protocol サーバーで Agent! をデータベース、API、ツールへ拡張。サブエージェントが作業を並列に分担 — 最大 6 つのリサーチャー。

Apple Intelligence を本物のエージェントとして

Agent! は、オンデバイスの Apple Intelligence を単なるテキスト生成ではなくツール呼び出しエージェントとして使う唯一の Mac AI エージェントです。以下はすべてあなたの Mac 上で動作し、デバイスの外に出ることはなく、API トークンを一切消費しません。

1次のステップの提案

タスクが終わると、Apple Intelligence がオンデバイスで結果を読み取り、次に取るべき手を一文で提案します — 「コミットしてプッシュ」、「テストを実行」、あるいは明らかな続きがなければ何も提案しません。クラウドとの往復も、トークンの消費もありません。

2トークン圧縮

約 30,000 トークンを超える長いタスクでは、古いターンをオンデバイスで要約 — ファイルパス、関数名、エラー、重要な結果は保持したまま — 残りのタスクの入力トークンとコストを大幅に削減します。

3ローカルトリアージ

雑談や 「list agents」、「run agent FooBar」 のような直接コマンドは、クラウド LLM と往復することなくローカルで処理 — 結果は 1 秒以内に 🍎 マーク付きでアクティビティログに表示されます。

4要約 & 分かりやすいエラー

タスクが完了するたびに、Apple Intelligence が一文の要約を書きます。ツールが失敗したときはエラーを分かりやすい言葉に翻訳するので、生のスタックトレースを読む必要はありません。

数分で使い始められます

Homebrew でもダウンロードでも。AI を選べば、あとは Agent! がすべて自動で設定します。

1

前提条件

  • macOS 26.4 (Tahoe) 以降、Apple Silicon 推奨
  • Xcode Command Line Tools：xcode-select --install
  • LLM の API キー — または Ollama、vLLM、LM Studio によるローカルモデル
2

インストール & 実行

  • Homebrew：brew install --cask agentiloop-agent
  • または DMG をダウンロードして Agent! を /Applications にドラッグ
  • Agent! を開き、Register をクリックしてバックグラウンドサービスをインストール
3

承認 & 設定

  • システム設定 → ログイン項目で Agent と AgentHelper を許可
  • 設定（⚙️）を開き、プロバイダーを選んで API キーを入力
  • Connect をクリックして XPC サービスをテスト
4

開始

  • 自然言語でタスクを入力
  • Run を押す（または ⌘Enter）
  • あとは Agent! におまかせ — 音声、iMessage、ハンズフリー操作も含めて
