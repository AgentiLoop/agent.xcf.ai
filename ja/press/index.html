AgentiLoop Agent! について

AgentiLoop Agent! は、コードエディタだけでなくコンピュータ全体を AI に任せる Mac アプリです。Xcode プロジェクトをビルドし、他のアプリを操作し、スクリプトを実行し、平易な英語の依頼からタスクを完了させます。

多くの AI コーディングツールはターミナル、エディタ、または Electron のウィンドウの中で動作し、その手が届く範囲はファイルシステムまでです。Mac のそれ以外の部分(アプリ、ウィンドウ、メニュー、スクリプト、ビルドツール)は対象外のままです。

AgentiLoop Agent! は純粋な Swift 6.2 と SwiftUI で作られています。Electron も Node もテレメトリもありません。自律ループ(計画、ツール呼び出し、実際の結果の観察、軌道修正、繰り返し)を実行し、ゴール基準が証拠付きで完了とマークされるまで、どのタスクも自らを完了と宣言できません。オプションのクリティックパスが事前に差分をレビューすることもできます。

Mac のあらゆる層に到達します。Accessibility API、AppleScript、JavaScript for Automation、および 51 の ScriptingBridge アプリブリッジによるあらゆるアプリの操作、クリック可能なエラー表示付きのネイティブ Xcode ビルド、ユーザー権限での、または一度承認したデーモン経由の root 権限でのシェルコマンド実行。Model Context Protocol サーバー、実行時にコンパイルされる Swift スクリプト、並列サブエージェントで拡張できます。音声での「Agent!」の呼びかけや、iPhone からの iMessage にも応答します。

どのモデルでも動作します。21 のプロバイダー(Claude、OpenAI、Gemini、DeepSeek、Qwen、OpenRouter、Requesty、A2Agent、OrcaRouter、およびローカルの Ollama、vLLM、LM Studio)に加え、デバイス上の Apple Intelligence がトークンコストゼロでトリアージ、要約、コンテキスト圧縮を担います。API キーはご自身でご用意ください。プロンプトとして選択したプロバイダーに送られるもの以外、Mac の外に出るものはありません。すべてのアクションはログに記録されます。

主な機能

AgentiLoop Agent! でできること

アプリ全体を貫くのはひとつの考え方です。AI は人が Mac でできることをすべてでき、その作業過程を示せるべきである、ということです。

  • 自己検証するタスクループ。 エージェントは推論し、ツールを実行し、実際の出力を観察して自らを修正します。ゴール基準が証拠付きで検証されるまでタスクを完了とマークすることはできず、オプトインのクリティックが完了前に差分をレビューします。
  • ネイティブ Xcode 統合によるエージェント型コーディング。 コードベースを読み取り、文字列置換の差分で編集し、クリック可能なエラー表示付きで Xcode プロジェクトをビルド・実行し、git を管理し、バージョンを更新し、リポジトリを持ち運び可能な JSONL リポジトリマップにインデックス化します。
  • Accessibility API によるデスクトップ自動化。 あらゆる Mac アプリを要素単位でクリック、入力、スクロール、読み取り、ナビゲートし、あいまい一致による自動リトライを備えます。さらに AppleScript、JavaScript for Automation、51 の ScriptingBridge アプリブリッジをすべてインプロセスで利用できます。
  • AgentScript:実行時にコンパイルされる Swift スクリプト。 エージェントは通常の Swift ファイルを書き、Swift Package Manager でダイナミックライブラリにコンパイルし、アプリ自身の権限でインプロセスに読み込みます。約 35 のサンプルがアプリに同梱され、削除したスクリプトは復元可能なゴミ箱に移動します。
  • すべての編集をロールバック可能。 各ファイル編集は実行前にスナップショットが取られ 1 週間保持されます。UI からのワンクリックロールバック、取り消しアクション、またはタスク全体の巻き戻しが可能です。
  • 21 の LLM プロバイダーとフォールバックチェーン。 Claude、Codex、OpenAI、Google Gemini、Grok、Mistral、Mistral Vibe、DeepSeek、Hugging Face、Z.ai、BigModel、Qwen、MiniMax、OpenRouter、Requesty、A2Agent、OrcaRouter、Ollama、ローカル Ollama、vLLM、LM Studio に加え、デバイス上の Apple Intelligence。プロバイダーが失敗またはレート制限された場合、エージェントは設定済みの次のプロバイダーに切り替えます。
  • デバイス上のエージェントとしての Apple Intelligence。 Apple の Foundation Models が、簡単な依頼をローカルでトリアージし、完了したタスクを要約し、ツールのエラーを平易な英語に言い換え、次のステップを提案し、長い会話を圧縮します。すべて Mac の外に出ることなく、API トークンも消費しません。
  • ユーザーが一度承認するだけの特権実行。 シェルコマンドは Launch Agent 経由でユーザー権限として、または Launch Daemon 経由で root として実行されます。いずれも SMAppService に登録され、XPC で接続されます。Launch Daemon はオプションです。
  • 多層防御。 シェル安全サービスがクライアント側とデーモン側の両方で壊滅的なコマンドをブロックします。両方の XPC リスナーは、アプリ自身の署名に基づく同一チームのコード署名を要求します。モデルが読んでいないファイルやディスク上で変更されたファイルへの編集は拒否され、すべてのツール呼び出しとヘルパーコマンドが監査ログに書き込まれます。詳細:docs/SECURITY.md
  • MCP サーバーとサブエージェント。 任意の Model Context Protocol サーバーを設定で追加でき、そのツールは自動的にエージェントから利用可能になります。最大 3 つの同時サブエージェント(読み取り専用なら 6 つ)が、エージェントごとのモデル上書きとメールボックスメッセージングを備えて分離環境で動作します。
  • 音声と iMessage によるリモート操作。 「Agent!」に続けてタスクを話すと、短い沈黙の後にデバイス上の音声認識を使って実行されます。承認済みの送信者は iPhone からタスクをテキストで送り、結果を iMessage で受け取れます。
  • タブ、メモリ、プラン、スキル。 各タブは独自のプロジェクトフォルダとアクティビティログを持ち、永続メモリはタスクをまたいで引き継がれ、複数ステップのプランチェックリストがすべてのプロンプトに表示され、長いタスクは各モデルの実際のコンテキストウィンドウに収まるよう圧縮されます。

フル解像度のスクリーンショット

macOS 26 上の AgentiLoop Agent! ウィンドウを Retina 解像度で PNG キャプチャしたもので、透明な角丸のウィンドウ単位で切り抜かれており、マーケティング用フレーム、キャプション、透かしはありません。いずれも開発者自身のプロジェクトでの実際のタスクを示しています。以前のバージョンのキャプチャには、本プロジェクトの旧 GitHub 組織名である macOS26 が表示されています。
